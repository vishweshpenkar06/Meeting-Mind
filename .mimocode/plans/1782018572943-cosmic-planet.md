# MeetingMind UI Overhaul — "Not AI Generated"

## Design Philosophy

The current design is a generic dark-mode SaaS template. Every AI tool looks like this. To make it feel **human-made and premium**, we need:

1. **Personality over polish** — Unique touches, not cookie-cutter components
2. **Tight design tokens** — ONE border radius, ONE shadow scale, consistent typography
3. **Intentional whitespace** — Let content breathe, don't fill every pixel
4. **Micro-details** — Subtle textures, noise, grain, custom iconography
5. **Human touches** — Handwritten-style accents, organic shapes, imperfect symmetry

---

## Phase 1: Design System Foundation

### File: `src/app/globals.css`

**Standardize border radius to ONE value: `12px`**
- All cards, inputs, buttons, tabs, modals → `rounded-xl` (12px)
- Only exception: `rounded-full` for avatars, badges, loading dots
- Delete: `rounded-[10px]`, `rounded-[14px]`, `rounded-2xl` from all components

**3-Level Shadow Scale:**
```
--shadow-sm: 0 1px 2px rgba(0,0,0,0.3)
--shadow-md: 0 4px 12px rgba(0,0,0,0.4)
--shadow-lg: 0 12px 40px rgba(0,0,0,0.5)
--shadow-glow: 0 0 24px rgba(79,142,247,0.15)
```

**Typography Scale (exact pixel values):**
```
--text-xs:   11px  (0.6875rem)  — labels, metadata
--text-sm:   13px  (0.8125rem)  — body, descriptions
--text-base: 15px  (0.9375rem)  — card titles, emphasis
--text-lg:   18px  (1.125rem)   — section headings
--text-xl:   24px  (1.5rem)     — page headings
--text-2xl:  32px  (2rem)       — hero/display
```

**New CSS variables to add:**
```css

--radius: 12px;
--radius-sm: 8px;
--radius-lg: 16px;
--radius-full: 9999px;
```
